# Prompt Engineering Kit

## Описание

Этот репозиторий — коллекция **системных промптов** для создания AI-агентов, способных решать реальные бизнес-задачи. Каждый промпт спроектирован по единому шаблону, протестирован на пограничных сценариях и готов к интеграции в корпоративные системы.

## Для чего это

- **Стандартизация** — единая структура для всех промптов (ROLE, GOAL, CONTEXT, TASK, INSTRUCTION, CONSTRAINTS, OUTPUT FORMAT)
- **Качество** — каждый промпт проверен на точность, релевантность, тон, безопасность и формат вывода
- **Безопасность** — встроенные guardrails против инъекций и обработки персональных данных
- **Масштабируемость** — промпты готовы к использованию в API и чат-ботах
- **Документированность** — каждый промпт имеет историю версий и результаты тестирования
